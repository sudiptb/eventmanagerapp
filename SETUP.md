# Quick setup

1. Open `EventManagerApp` in Android Studio.
2. Install/choose JDK 17.
3. Add `app/google-services.json` from your Firebase project.
4. Enable Firebase Authentication -> Email/Password.
5. Create Firestore.
6. Apply `firestore.rules`.
7. Sync Gradle and run.

The project uses Android Gradle Plugin 8.13.2, Kotlin 2.3.20, compile/target SDK 36, and Firebase BoM 34.19.0.
