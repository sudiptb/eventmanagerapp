# Event Manager - Kotlin + Firebase

A 2-day assignment implementation based on the supplied Event Management App specification.

## Included
- Kotlin + XML
- MVVM + Repository Pattern
- Firebase Email/Password Authentication
- Password reset
- Persistent Firebase login session
- Firestore events per authenticated user
- Add / edit / delete events
- Reverse chronological event list
- Firestore realtime listener
- Dashboard totals: total/upcoming/past
- MPAndroidChart monthly bar chart
- Firestore persistent offline cache
- Input validation
- Firebase error handling
- Firebase Cloud Messaging receiver (bonus foundation)
- DayNight Material theme for dark-mode support
- Unit test example

## Firebase setup
1. Create a Firebase project.
2. Add an Android app using application id `com.example.eventmanager`.
3. Download `google-services.json` and place it in `app/google-services.json`.
4. In Firebase Authentication, enable Email/Password.
5. Create a Cloud Firestore database.
6. Deploy the rules from `firestore.rules` or add equivalent rules in the Firebase console.
7. For FCM, enable Cloud Messaging and send a test notification from Firebase Console.

Firebase's current Android setup recommends the Firebase Android BoM and the main Firebase modules rather than the retired KTX modules.

## Firestore structure
users/{uid}/events/{eventId}

Fields:
- title: string
- description: string
- dateTime: timestamp
- location: string

## Build
Open this folder in Android Studio with JDK 17. Let Gradle sync, add `google-services.json`, then Run.

## Important
The FCM service is included as the client-side notification receiver. Automatic scheduled reminders require a trusted server/Cloud Function or another scheduling mechanism; they are not generated by the client service itself.
